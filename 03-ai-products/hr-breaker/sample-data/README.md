# Sample Data

Synthetic sample files for demo and testing.

## Quick demo

```bash
# Web UI
uv run hr-breaker serve
# Open http://localhost:8899
# Drop sample-data/resume.txt, paste contents of job-description.txt, click Optimize

# CLI
uv run hr-breaker optimize sample-data/resume.txt sample-data/job-description.txt
```

## Files

- `resume.txt` — synthetic software engineer resume (no real personal data)
- `job-description.txt` — synthetic Senior Backend Engineer job posting

These files contain no real personal information and are safe for public use.
