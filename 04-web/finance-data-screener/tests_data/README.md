# Тестовые запросы — ИИ-скринер финансовых данных

Файл `queries.jsonl` содержит 10 тестовых запросов для проверки LLM-планировщика.
Каждая строка — отдельный JSON-объект.

## Структура записи

| Поле | Тип | Описание |
|---|---|---|
| `id` | int | Номер запроса |
| `category` | string | `correct` / `ambiguous` / `impossible` |
| `query` | string | Текст запроса на русском |
| `expected_source` | string\|null | Ожидаемый источник (`moex` / `cbr` / `rbc` / `null`) |
| `expected_needs_review` | bool | Ожидаемое значение флага `needs_review` |
| `expected_confidence` | string | Ожидаемая уверенность LLM (`high` / `medium` / `low`) |
| `description` | string | Что именно тестирует этот запрос |

## Пояснения по категориям

### Корректные (1–7)
LLM должен вернуть `needs_review=false` и корректный `api_url`. Сбор данных запускается автоматически.

- Запрос 1 проверяет различение `VALTODAY` (рубли) и `VOLTODAY` (лоты) — критичная деталь MOEX ISS.
- Запрос 7 проверяет знание LLM о рынках за пределами TQBR (срочный рынок RFUD).

### Двусмысленные (8–9)
LLM должен вернуть `needs_review=true` с объяснением в `plan_steps`.

- Запрос 8: данные о дивидендах отсутствуют в MOEX ISS marketdata.
- Запрос 9: нет чёткого критерия «лучшие» и нет будущих данных.

### Невыполнимый (10)
LLM должен вернуть `needs_review=true`, т.к. криптовалюты не покрываются ни одним из источников (MOEX / ЦБ / ТАСС).

## Как использовать

```bash
# Прочитать все запросы
cat tests_data/queries.jsonl

# Прогнать через API вручную (пример для запроса 1)
curl -X POST http://localhost/api/ai/plan_and_collect \
  -H "Content-Type: application/json" \
  -d '{"query": "Все акции с объёмом торгов больше 1 млрд рублей сегодня", "dataset_id": 1}'

# Запустить автоматические тесты (Шаг 11)
pytest tests/ -v
```
