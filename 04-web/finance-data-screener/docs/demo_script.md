# Сценарий демо-видео — ИИ-скринер финансовых данных

**Формат:** запись экрана + голос. Длина: 2–4 минуты.  
**Перед записью:** система запущена (`docker compose -p screener up`), браузер открыт на `http://localhost`.

---

## Структура (3 минуты)

| Блок | Время | Что на экране |
|---|---|---|
| Вступление | 0:00–0:20 | Стартовый экран приложения |
| Демо 1 — успешный сбор | 0:20–1:20 | Сбор, план, витрина |
| Демо 2 — needs_review | 1:20–2:00 | ReviewBanner |
| Витрина и экспорт | 2:00–2:40 | Таблица, график, экспорт |
| Журнал | 2:40–3:00 | AuditPage |

---

## Текст по секундам

### 0:00–0:20 — Вступление

*Показать: стартовый экран, вкладка «Наборы данных»*

> «Это ИИ-скринер финансовых данных. Пользователь вводит запрос на русском языке — система разбирает его через языковую модель, строит план сбора, забирает данные из открытых источников и показывает результат. Никаких ключей API от сторонних платных сервисов — все источники бесплатные.»

---

### 0:20–0:40 — Создание датасета и запрос

*Показать: вкладка «Сбор», кнопка «Создать датасет»*

> «Создам датасет. Называю его "Объём торгов".»

*Действие: кнопка «Новый датасет», ввести название «Объём торгов», нажать «Создать»*

*Показать: dropdown с датасетом выбран, textarea запроса*

> «В поле запроса пишу: "Все акции с объёмом торгов больше 1 миллиарда рублей сегодня".»

*Действие: ввести запрос, нажать «Спланировать»*

---

### 0:40–1:20 — PlanPreview и сбор

*Показать: PlanPreview появился*

> «Языковая модель разобрала запрос. Видим план: источник — MOEX, API-URL уже построен, поля — SECID, LAST, VALTODAY, фильтр — VALTODAY больше миллиарда. Уверенность — высокая. Нажимаю "Собрать".»

*Действие: нажать «Собрать»*

*Показать: успешный результат — «Собрано N записей»*

> «Готово — система собрала данные и сохранила их. Перехожу на Витрину.»

---

### 1:20–2:00 — needs_review (второй запрос)

*Показать: вернуться на «Сбор», выбрать или создать второй датасет*

*Действие: ввести «Акции с хорошими дивидендами», нажать «Спланировать»*

*Показать: ReviewBanner*

> «Теперь другой запрос — "Акции с хорошими дивидендами". Языковая модель выставила флаг needs_review — данных о дивидендах в MOEX ISS нет. Баннер сообщает причину и предлагает уточнить запрос. Сбор не запускается — это правильное поведение.»

---

### 2:00–2:40 — Витрина

*Показать: ShowcasePage, выбрать датасет «Объём торгов»*

> «На Витрине выбираю датасет. Данные — в таблице: тикер, цена, объём в рублях. Справа — гистограмма по объёму торгов. Система автоматически определила числовое поле для графика.»

*Действие: прокрутить таблицу, посмотреть на график*

> «Экспортирую в CSV — файл готов к открытию в Excel.»

*Действие: нажать «CSV»*

---

### 2:40–3:00 — Журнал

*Показать: AuditPage*

> «Раздел "Журнал" — здесь каждый запрос к API залогирован автоматически: метод, эндпоинт, статус, время ответа. Middleware работает незаметно для пользователя.»

---

## Советы по записи

- Записывать в разрешении 1920×1080
- Скрыть панель закладок браузера (Ctrl+Shift+B)
- Перед записью: сделать 1 тестовый сбор чтобы данные уже были в Витрине
- Если интернет медленный — заранее собрать данные, на демо только показывать таблицу
- Монтаж не нужен — можно записать за один дубль по этому сценарию
