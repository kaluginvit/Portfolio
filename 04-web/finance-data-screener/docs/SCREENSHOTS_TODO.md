## 2. Сбор данных — Review Flow

**Файл:** `docs/screenshots/02-collect-review.png`

**Шаги:**
1. Перейти в раздел «Сбор»
2. Выбрать датасет (или создать новый: «Тест»)
3. Ввести запрос: *«Акции MOEX с объёмом торгов больше 1 млрд»*
4. Дождаться ответа LLM с планом
5. Сделать скриншот — должен быть виден план (источник, URL, поля) и кнопка «Собрать»
